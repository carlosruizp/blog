This is the first post. It exists to show what a post looks like once it's
built: a title, a byline with the date, and a body written in a small
subset of Markdown — paragraphs, **bold**, *italics*, `inline code`,
[links](https://example.com), block quotes, and simple lists.

> Style is not neutral; it is ideological, and the plainness of this page
> is a choice as much as any other.

Some things this template deliberately does *not* have: hero images, card
grids, animated transitions, a cookie banner, a newsletter popup, or a
"reading time" estimate. Just a title, a date, and the text.

To add a new post, drop another `.md` file into `content/posts/` with the
same front matter block, then run:

`python3 build.py`

- edit `content/config.json` for the site title, tagline, and about blurb
- edit `content/about.md` for the about page
- edit `templates/base.html` for the blogroll links in the sidebar
